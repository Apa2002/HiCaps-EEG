# Code and material availability

## Current release

This repository provides a research summary, conceptual figures, and aggregate results reported in the submitted HiCaps-EEG manuscript.

Source code is not publicly available at this stage. No public release date is specified.

## Included

- Research overview and method summary.
- Evaluation-protocol descriptions.
- Reported overall, ablation, and temporal values.
- Documentation figures.

## Not included in this release

- Training, inference, or evaluation programs.
- Model checkpoints or configuration files.
- Exact data-split assignments.
- Trial-level outputs.
- A copy of the submitted manuscript or dataset.

The original public EEG dataset is hosted by the [Stanford Digital Repository](https://purl.stanford.edu/bq914sc3730).
